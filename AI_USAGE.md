# AI Usage Notes

AI tools were used as development assistance during the development of this project.

## Tools Used

- **ChatGPT** – Assisted with project planning, Laravel implementation guidance, debugging, code review, and API documentation.

## Areas of Assistance

AI assistance was used for:

- Planning the API structure and database model.
- Understanding Laravel controllers, models, migrations, and form requests.
- Reviewing input validation and API response handling.
- Identifying and resolving implementation issues.
- Preparing API documentation and automated test scenarios.

## Developer Responsibility

All generated suggestions and code were reviewed, adapted, and tested by the developer.

The developer is responsible for understanding the implementation and verifying that the API works according to the assignment requirements.
